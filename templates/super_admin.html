🔴 Super Admin God Mode

Full access to all users, logs, analytics, security
Change any user's role (Admin / User)
Block, unblock, delete any user
View all audit logs and security alerts
View all analytics and data visualizations
Access system controls panel
Protected — cannot be blocked, deleted, or role-changed by anyone

🔵 Admin Moderator

View own profile and login history
View all system audit logs (read-only)
View login analytics and charts
Block or unblock non-super-admin users only
Cannot change any user's role
Cannot delete users
Cannot access security alerts or controls panel

🟢 User Standard

View own profile (name, email, role, status)
View own login activity and risk scores
View own security info (last device, location)
Edit own display name
Cannot see any other user's data
No access to system logs, analytics, or admin features
